Uma página web simples que demonstra os conceitos básicos de **HTML** e **CSS**:

- ✅ **Título da página:** "Página da Atividade 1"
- ✅ **Conteúdo:** Texto e imagem relacionada ao tema "Vargol"

## 📝 Detalhes do Código

### **HTML** - `index.html`
- Estrutura básica com head e body
- Link externo para stylesheet CSS
- Elemento div com classe `.vargol` para centralização
- Título `<h1>` e parágrafo `<p>`
- Imagem inserida no diretório `/images`

### **CSS** - `style.css`
- **Body:** Cor preta, fonte Arial, tamanho 20px, fundo cinza (#A7A7A7)
- **H1:** Cor preta
- **.vargol:** Alinhamento de texto centralizado
